## [0.1.0] - 2024-11-23

### Added
- Initial release of ScrapeDrive Python SDK
- Synchronous client (`ScrapeDrive`)
- Asynchronous client (`AsyncScrapeDrive`)
- Support for JavaScript rendering
- Support for residential and datacenter proxies
- Configurable proxy countries
- Automatic HTML to Markdown conversion
- Context manager support
- Comprehensive error handling with custom exceptions
- Type hints throughout the codebase
- Full test coverage with pytest
- CI/CD pipeline with GitHub Actions
- Documentation and usage examples
